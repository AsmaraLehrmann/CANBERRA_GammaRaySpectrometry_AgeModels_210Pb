# This repository contains tools for 
1) extracting radioisotope values from Canberra produced PDFs (210Pb_AgeModelPlot.ipynb)
2) plotting preliminary lead-210 age models (210Pb_AgeModelPlot.ipynb)
3) aiding in determining sedimentation rate and mass accumulation rate (sedimentation_rate.py and mass_accumulation_rate.py)
4) aiding in developing final age model plots (agemodel_plotter.py)
